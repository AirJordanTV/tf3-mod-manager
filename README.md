# TF3 Mod Manager

Mod Manager für Transport Fever 3 von **AirJordanTV**.

Hier gibts nur die Downloads, der Code selber ist privat.

## Download

👉 **[Neueste Version holen](https://github.com/AirJordanTV/tf3-mod-manager/releases/latest)**

- `TF3ModManager_Komplett_v….zip` – einfach entpacken und starten, läuft ohne extra .NET. Wenn du nicht weißt was du nehmen sollst, nimm die.
- `TF3ModManager.exe` – die kleine Variante, braucht .NET 8 Desktop Runtime.

Updates zeigt der Manager von selber an, musst hier also nicht ständig reinschauen.

## Was kann der?

- Mods reinziehen (Ordner oder Zip), an/aus machen, Reihenfolge per Drag & Drop
- zeigt Konflikte an (gleiche Dateien, fehlende Abhängigkeiten, inkompatible Mods …)
- Profile für verschiedene Spielstände
- mod.io direkt im Manager: suchen, runterladen, abonnieren
- englische Beschreibungen werden automatisch auf Deutsch übersetzt
- zeigt Updates für deine Mods an

Fragen, Fehler, Wünsche? Am besten im Thread auf transportfever.net melden.
